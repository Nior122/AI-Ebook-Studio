# Prompt Engineering

## Prompt System

Prompts are grouped by domain in `prompts/`. Each template should document:

- Purpose
- Required inputs
- Output format
- Quality constraints
- Safety and policy constraints

## Rules

- Do not bake provider-specific syntax into product prompts unless the provider adapter owns it.
- Prefer structured outputs for machine-readable results.
- Keep system prompts separate from task prompts.
- Version prompts when behavior changes materially.

## Planned Prompt Areas

- Writing
- Editing
- Marketing
- Translation
- Cover design
- Image generation
- Validation
- System behavior
