# UI Design System

## Design Language

AI Ebook Studio uses a modern Apple-inspired interface: minimal, calm, precise, spacious, and highly readable.

## Visual Principles

- Light mode first, with complete dark mode support.
- Clean neutral surfaces.
- Rounded cards with 8px radius.
- Soft shadows used sparingly.
- Clear spacing rhythm.
- Responsive layouts that support desktop writing workflows and mobile review.

## Components

- Buttons use shadcn/ui variants.
- Cards are for repeated objects, panels, and modals.
- Forms use clear labels, helper text, validation, and accessible focus states.
- Navigation should be predictable and restrained.

## Color

The foundation uses semantic Tailwind tokens:

- `background`
- `foreground`
- `card`
- `primary`
- `secondary`
- `muted`
- `accent`
- `destructive`
- `border`
- `ring`

## Interaction

Interactions should feel quick and quiet. Avoid heavy animation. Use motion only to clarify state changes.
